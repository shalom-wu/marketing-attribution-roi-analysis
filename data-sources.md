# Data Sources

## Selected Data Source

This project uses a deterministic synthetic dataset generated by `src/attribution_roi/synthetic.py` and written to `data/synthetic/customer_journeys.csv`.

The data is synthetic. It is not real customer data, not a scraped dataset, and not a Kaggle download.

## Why Synthetic Data Was Used

The project brief asked for a public multi-touch attribution dataset with user-level journeys, touchpoint dates, marketing channels, and conversion outcomes. Public marketing attribution datasets exist in several forms, but for this portfolio build I did not select one that was both cleanly accessible and sufficiently documented for a public GitHub project. Rather than imply provenance that I could not fully support, I generated a clearly labeled synthetic dataset.

## Dataset Grain

Each row represents one marketing touchpoint in a customer journey.

Core fields:

| Column | Meaning |
|---|---|
| `user_id` | Synthetic customer identifier |
| `journey_id` | Synthetic journey identifier |
| `touchpoint_id` | Unique touchpoint identifier |
| `touchpoint_sequence` | Order of the touch within the journey |
| `touchpoint_date` | Synthetic touchpoint date |
| `channel` | Marketing channel |
| `channel_stage` | Awareness, consideration, or decision stage |
| `converted` | Journey-level conversion outcome repeated on each touchpoint |
| `conversion_probability` | Synthetic probability used during generation |
| `conversion_date` | Date for converted journeys; blank otherwise |
| `revenue` | Synthetic order revenue for converted journeys |

## Synthetic Generation Methodology

The generator creates 15,000 journeys across eight channels:

- Display
- Paid Social
- Referral
- Organic Search
- Paid Search
- Affiliate
- Email
- Direct

Journey paths are generated with different first-touch, middle-touch, and last-touch channel probabilities. This intentionally reflects a common marketing pattern: upper-funnel channels appear earlier, while Paid Search, Email, and Direct appear more often near conversion.

Conversion is generated with a logistic-style scoring function based on:

- Channel presence in the journey
- Journey length
- Lower-funnel final touches
- Synergy when upper-funnel and lower-funnel channels appear together
- Small penalties for repeated touches and very long journeys

Converted journeys receive capped lognormal synthetic revenue. The random seed is fixed at `42`, so the dataset is reproducible.

## Budget Assumptions

The repo uses a synthetic current-quarter budget for a mid-size e-commerce business:

| Channel | Current Quarter Budget |
|---|---:|
| Display | $14,000 |
| Paid Social | $18,000 |
| Referral | $6,000 |
| Organic Search | $24,000 |
| Paid Search | $55,000 |
| Affiliate | $20,000 |
| Email | $22,000 |
| Direct | $15,000 |

These assumptions are designed to demonstrate a last-touch-heavy budget mix. They should be replaced with real spend, margin, and customer lifetime value inputs in a production analysis.

## Important Caveat

Attribution outputs are correlational. They allocate credit across observed paths but do not prove that a channel caused the conversion. Any real budget move should be validated with incrementality testing, geo holdouts, randomized experiments, or media-mix modeling.
